# VibeTube

**Watch. Vibe. Your Way.**

VibeTube is a modern video experience focused on smooth playback, Shorts, downloads, background playback, and a clean user interface.

## Latest Release

**Version:** 1.0.1

Check the [Releases](../../releases) section for the latest APK.

## Update System

VibeTube uses GitHub Releases for distributing app updates.

- `version.json` — latest version information
- GitHub Releases — APK distribution

## Features

- Smooth video playback
- Shorts
- Search
- Background playback
- Offline downloads
- High-quality video playback
- Playlists and subscriptions
